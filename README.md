# Odin Recipes

This is my first web development project from [The Odin Project](https://www.theodinproject.com/). 

## Description
In this project, I built a basic recipes website using fundamental HTML concepts. 

### What I learned:
* Setting up HTML boilerplate code
* Using text formatting tags like `<h1>`, `<h2>`, and `<p>`
* Creating unordered (`<ul>`) and ordered (`<ol>`) lists
* Embedding images with the `<img>` tag
* Linking relative pages using the `<a>` tag
* Managing version control with Git and GitHub
